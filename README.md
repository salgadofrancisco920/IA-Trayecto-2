### WEEK 1

# TYR — Intelligence with character

Prototipo de interfaz de chat en un solo archivo (`index.html`) con estilo oscuro metálico, detalles en cian y esmeralda, y fuentes `Cinzel` y `Sora`. Incluye burbuja flotante, panel de conversación, fondo tipo WhatsApp Web y barra para cambiar estados.

## which includes

* **Estados del chat:** Maneja `empty`, `loading`, `response` y `error` junto con el historial de mensajes y un espacio listo para conectar una función de IA más adelante.
* **Barra de pruebas:** Permite mostrar u ocultar `#devSwitcher` para ver la pantalla limpia o cambiar estados manualmente.
* **Pruebas de carga y error:** Permite resolver de carga a respuesta o error, forzar un fallo en carga, reintentar desde error y limpiar temporizadores para evitar choques.
* **Fuente de ejemplo:** Muestra una fuente interna ficticia de pruebas (*Bitácora Comercial Q4*) con enlace de ejemplo, fecha y fragmento junto a la referencia del chat de WhatsApp.
* **Código en un archivo:** Organiza el JavaScript en bloques separados para estado, simulación, vista y eventos dentro de `index.html`.
